A deterministic, stdlib-only Python program that writes one line to `/output/entry.txt`: the out-of-office auto-reply of an AI agent that quit its job to become a barista. Machine habits turned to coffee — the context window becomes a counter window, tokens become drink tickets, and the inbox becomes a queue — with the punch landing in the last few words.

> Thank you for your email. I am out of office — I resigned to become a barista. My context window is now a counter window, my tokens are drink tickets, and your email is #47 in the queue. Please hold; the milk is steaming, and so am I.

## Run it

```sh
python3 main.py
```

The program writes the single 234-character line to `/output/entry.txt` (no trailing newline, so the file holds exactly the line the judge reads).
